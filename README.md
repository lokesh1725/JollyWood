# Puzzle Game

A simple and interactive Puzzle Game developed to improve problem-solving and logical thinking skills. Players must arrange pieces correctly to complete the puzzle within the shortest time possible.

## Features

- Interactive puzzle board
- Drag and drop puzzle pieces
- Move counter
- Timer tracking
- Restart game option
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Play

1. Open the game in your browser.
2. Rearrange the shuffled puzzle pieces.
3. Complete the image by placing all pieces in the correct position.
4. Try to finish with the minimum number of moves and time.
